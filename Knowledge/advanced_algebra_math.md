# CHAPTER 2: ADVANCED ALGEBRA


## Abstract Algebra

### Group Theory (Advanced)

**Normal Subgroups:**
N ⊲ G iff ∀g ∈ G: gNg⁻¹ = N
Equivalently: N is the kernel of some homomorphism.

**Quotient Group:**
G/N = {gN : g ∈ G} with operation (gN)(hN) = (gh)N
Well-defined iff N is normal.

**Isomorphism Theorems:**
1. First:  φ: G → H homomorphism ⇒ G/ker(φ) ≅ im(φ)
2. Second: H ≤ G, N ⊲ G ⇒ H/(H∩N) ≅ HN/N
3. Third:  N ⊲ G, M ⊲ G, N ⊆ M ⇒ (G/N)/(M/N) ≅ G/M

**Composition Series:**
A series 1 = G₀ ⊲ G₁ ⊲ ... ⊲ Gₙ = G where each G_{i+1}/Gᵢ is simple.
**Jordan-Hölder Theorem:** Any two composition series have the same length and same simple factors (up to permutation).

**Sylow Theorems:**
For |G| = pⁿ·m where p ∤ m:
1. ∃ subgroup of order pⁿ (Sylow p-subgroup)
2. All Sylow p-subgroups are conjugate
3. Number of Sylow p-subgroups ≡ 1 (mod p) and divides m

**Solvable Groups:**
G is solvable if ∃ series 1 = G₀ ⊲ G₁ ⊲ ... ⊲ Gₙ = G with each G_{i+1}/Gᵢ abelian.
- All abelian groups are solvable
- Sₙ is not solvable for n ≥ 5
- **Feit-Thompson Theorem:** Every finite group of odd order is solvable

**Nilpotent Groups:**
Upper central series reaches G in finitely many steps.
- Every nilpotent group is solvable
- Finite p-groups are nilpotent
- Direct product of nilpotent groups is nilpotent

**Free Groups:**
F(S) = group generated by set S with no relations except those required by group axioms.
- Universal property: Any function S → G extends uniquely to homomorphism F(S) → G
- Every group is a quotient of a free group

**Group Presentations:**
G = ⟨S | R⟩ where S = generators, R = relations
Example: Dₙ = ⟨r, s | rⁿ = s² = 1, srs = r⁻¹⟩ (dihedral group)

**Group Cohomology:**
Hⁿ(G, M) for G-module M.
- H¹(G, M) = crossed homomorphisms / principal crossed homomorphisms
- H²(G, M) = equivalence classes of group extensions
- Connection to topology: Hⁿ(G, ℤ) = Hⁿ(BG, ℤ) where BG is classifying space

### Ring Theory (Advanced)

**Ideals:**
- Left ideal: closed under left multiplication
- Right ideal: closed under right multiplication
- Two-sided ideal: both
- Principal ideal: (a) = {ra : r ∈ R}

**Prime & Maximal Ideals:**
- P is prime: ab ∈ P ⇒ a ∈ P or b ∈ P
- M is maximal: no ideal strictly between M and R
- In commutative rings with unity: maximal ⇒ prime
- In PIDs: prime = maximal = (p) for irreducible p

**Factorization in Rings:**
- UFD: Unique factorization domain
- PID: Principal ideal domain (every ideal is principal)
- Euclidean domain: has division algorithm
- ED ⇒ PID ⇒ UFD

**Examples:**
- ℤ is ED, PID, UFD
- ℤ[x] is UFD but not PID
- ℚ[x,y] is UFD but not PID
- ℤ[√-5] is not UFD: 6 = 2·3 = (1+√-5)(1-√-5)

**Noetherian Rings:**
Every ascending chain of ideals stabilizes (ACC).
Equivalently: every ideal is finitely generated.

**Hilbert's Basis Theorem:**
If R is Noetherian, then R[x] is Noetherian.

**Localization:**
For multiplicative set S ⊆ R, S⁻¹R = {r/s : r ∈ R, s ∈ S}
Example: ℤ_{(p)} = {a/b ∈ ℚ : p ∤ b} (localization at prime p)

**Chinese Remainder Theorem (Rings):**
If I₁, ..., Iₙ are pairwise comaximal ideals (Iᵢ + Iⱼ = R for i ≠ j):
R/(I₁∩...∩Iₙ) ≅ R/I₁ × ... × R/Iₙ

### Module Theory

A module M over ring R is an abelian group with scalar multiplication r·m satisfying:
- r·(m₁ + m₂) = r·m₁ + r·m₂
- (r₁ + r₂)·m = r₁·m + r₂·m
- (r₁r₂)·m = r₁·(r₂·m)
- 1·m = m (if R has unity)

**Free Module:** M ≅ Rⁿ (direct sum of n copies of R)
**Projective Module:** Direct summand of a free module
**Injective Module:** Dual notion (splits all short exact sequences)
**Flat Module:** Tensor product preserves exactness

**Structure Theorem for Finitely Generated Modules over PID:**
Any such M is isomorphic to:
M ≅ Rʳ ⊕ R/(p₁^a₁) ⊕ ... ⊕ R/(pₖ^aₖ)
where pᵢ are irreducible and r is the rank (free part).

**Special case (ℤ-modules = abelian groups):**
Every finitely generated abelian group:
G ≅ ℤʳ ⊕ ℤ/p₁^a₁ ⊕ ... ⊕ ℤ/pₖ^aₖ

**Exact Sequences:**
... → M_{i-1} → Mᵢ → M_{i+1} → ... is exact at Mᵢ if im(f_{i-1}) = ker(fᵢ)

Short exact sequence: 0 → A → B → C → 0
- B is extension of C by A
- Splits iff B ≅ A ⊕ C (iff ∃ section C → B)

**Tensor Products:**
M ⊗_R N = free abelian group on M × N / relations:
- (m₁+m₂, n) = (m₁,n) + (m₂,n)
- (m, n₁+n₂) = (m,n₁) + (m,n₂)
- (mr, n) = (m, rn)

Properties:
- R ⊗_R M ≅ M
- (M ⊕ N) ⊗ P ≅ (M ⊗ P) ⊕ (N ⊗ P)
- M ⊗ N ≅ N ⊗ M (for commutative R)
- Not always exact: 0 → ℤ → ℤ → ℤ/2 → 0, tensor with ℤ/2 gives non-exact sequence

**Hom Functors:**
Hom_R(M, -) and Hom_R(-, M)
- Hom_R(M, -) is left exact
- Hom_R(-, M) is left exact (contravariant)

### Field Theory

**Algebraic Extensions:**
- α is algebraic over F if ∃ p(x) ∈ F[x], p ≠ 0: p(α) = 0
- Minimal polynomial: monic irreducible polynomial of α
- [F(α):F] = degree of minimal polynomial

**Splitting Field:**
Smallest extension containing all roots of a polynomial.
Example: Splitting field of x³ - 2 over ℚ is ℚ(∛2, ω) where ω = e^{2πi/3}

**Normal Extension:**
Algebraic extension where every irreducible polynomial with one root splits completely.
Equivalently: splitting field of some set of polynomials.

**Separable Extension:**
Every element has separable minimal polynomial (no repeated roots).
- In characteristic 0, all algebraic extensions are separable
- In characteristic p, inseparable extensions exist

**Galois Extension:**
Normal + Separable

**Galois Group:**
Gal(E/F) = Aut(E/F) = {σ: E → E : σ|_F = id}

**Fundamental Theorem of Galois Theory:**
For Galois extension E/F, there is a bijection:
{Subgroups of Gal(E/F)} ↔ {Intermediate fields F ⊆ K ⊆ E}
H ↦ E^H (fixed field)
Gal(E/K) ↔ K

Properties:
- [E:K] = |Gal(E/K)|
- K/F is normal iff Gal(E/K) ⊲ Gal(E/F)
- Gal(K/F) ≅ Gal(E/F) / Gal(E/K)

**Solvability by Radicals:**
A polynomial is solvable by radicals iff its Galois group is solvable.
- General quintic: Galois group S₅, not solvable ⇒ no general radical formula
- Some quintics are solvable (e.g., x⁵ - 2 = 0 has cyclic Galois group)

**Cyclotomic Extensions:**
ℚ(ζₙ) where ζₙ = e^{2πi/n} (primitive n-th root of unity)
- [ℚ(ζₙ):ℚ] = φ(n)
- Gal(ℚ(ζₙ)/ℚ) ≅ (ℤ/nℤ)*

**Finite Fields:**
𝔽_{pⁿ} = GF(pⁿ)
- Unique field of order pⁿ for each prime p, n ≥ 1
- Multiplicative group is cyclic
- 𝔽_{pⁿ} is splitting field of x^{pⁿ} - x over 𝔽_p
- Gal(𝔽_{pⁿ}/𝔽_p) ≅ ℤ/nℤ, generated by Frobenius x ↦ x^p

### Representation Theory

**Group Representations:**
A representation of G is a homomorphism ρ: G → GL(V) where V is a vector space.
Equivalently: V is a module over group algebra ℂ[G].

**Irreducible Representation:**
No non-trivial invariant subspaces.
**Maschke's Theorem:**
For finite G and char(F) ∤ |G|, every representation is completely reducible (direct sum of irreducibles).

**Character Theory:**
Character χ_ρ(g) = tr(ρ(g))
- χ is a class function (constant on conjugacy classes)
- Number of irreducible representations = number of conjugacy classes
- Orthogonality relations:
  (1/|G|) Σ_g χᵢ(g) χⱼ(g)̄ = δᵢⱼ

**Burnside's Theorem:**
Every group of order p^a q^b (p,q primes) is solvable.

**Frobenius Reciprocity:**
For H ≤ G, representation V of G, W of H:
Hom_G(V, Ind_H^G(W)) ≅ Hom_H(Res_H^G(V), W)


## Linear Algebra (Advanced)

### Multilinear Algebra

**Tensor Products of Vector Spaces:**
V ⊗ W = bilinear maps on V* × W*
- dim(V ⊗ W) = dim(V) · dim(W)
- Basis: {vᵢ ⊗ wⱼ} for bases {vᵢ}, {wⱼ}

**Tensor Algebra:**
T(V) = ⊕_{k=0}^∞ V^{⊗k}
- Free algebra on V
- Universal property: any linear map V → A extends to algebra homomorphism T(V) → A

**Symmetric Algebra:**
S(V) = T(V) / (v⊗w - w⊗v)
- Polynomials in basis elements
- S(V) ≅ F[x₁, ..., xₙ] for dim(V) = n

**Exterior Algebra (Grassmann Algebra):**
Λ(V) = T(V) / (v⊗v)
- v ∧ w = -w ∧ v
- v ∧ v = 0
- dim(Λ^k(V)) = C(n,k) for dim(V) = n
- Λ^n(V) is 1-dimensional (top exterior power)

**Applications:**
- Determinants: det = top exterior power of linear map
- Differential forms: sections of Λ(T*M)
- Orientation: choice of element in Λ^n(V)\{0}

### Spectral Theory

**Eigenvalues & Eigenvectors:**
Av = λv for v ≠ 0
- Characteristic polynomial: det(A - λI) = 0
- Algebraic multiplicity: multiplicity as root of char poly
- Geometric multiplicity: dim(ker(A - λI))

**Diagonalization:**
A is diagonalizable iff it has n linearly independent eigenvectors.
Equivalently: minimal polynomial has no repeated roots.

**Jordan Canonical Form:**
For any A over algebraically closed field:
A = PJP⁻¹ where J is block diagonal with Jordan blocks:
```
J_k(λ) = | λ  1        |
         |    λ  1      |
         |       ...  1 |
         |          λ   |
```
- Number of Jordan blocks for λ = geometric multiplicity
- Size of largest block = index of λ in minimal polynomial

**Spectral Theorem (Normal Operators):**
For A normal (A*A = AA*) on finite-dimensional inner product space:
- A is unitarily diagonalizable
- Eigenvectors for distinct eigenvalues are orthogonal
- Special cases: Hermitian (real eigenvalues), Unitary (|λ| = 1)

**Singular Value Decomposition (SVD):**
Any m×n matrix A can be written:
A = UΣV*
where U (m×m) and V (n×n) are unitary, Σ is diagonal with non-negative entries (singular values).

**Applications of SVD:**
- Low-rank approximation
- Principal Component Analysis (PCA)
- Pseudoinverse: A⁺ = VΣ⁺U*
- Condition number: κ(A) = σ_max / σ_min

### Operator Theory (Infinite Dimensions)

**Hilbert Spaces:**
Complete inner product space.
Examples: L²(ℝ), ℓ²(ℕ)

**Bounded Operators:**
T: H → H linear with ||T|| = sup_{||x||=1} ||Tx|| < ∞
- B(H) = algebra of bounded operators
- Spectrum: σ(T) = {λ : T - λI not invertible}

**Spectral Theorem (Bounded Self-Adjoint):**
T = T* on Hilbert space H:
- σ(T) ⊆ ℝ
- T = ∫_{σ(T)} λ dE(λ) (spectral integral)
- There exists unitary U: H → L²(μ) such that UTU* is multiplication operator

**Compact Operators:**
T maps bounded sets to relatively compact sets.
- Spectrum: countable, 0 is only possible accumulation point
- Fredholm Alternative: For T compact, I - T is either invertible or has finite-dimensional kernel

**Unbounded Operators:**
- Defined on dense subspace
- Self-adjoint: T = T* (with appropriate domain)
- Spectrum can be continuous
- Applications: Quantum mechanics (Hamiltonian operators)

### Lie Algebras & Lie Groups

**Lie Group:**
Smooth manifold with group structure where multiplication and inversion are smooth.
Examples: GL(n,ℝ), SL(n,ℝ), O(n), SO(n), U(n), SU(n), Sp(2n)

**Lie Algebra:**
Vector space g with bilinear bracket [·,·] satisfying:
- [X,Y] = -[Y,X] (skew-symmetry)
- [X,[Y,Z]] + [Y,[Z,X]] + [Z,[X,Y]] = 0 (Jacobi identity)

**Lie Algebra of a Lie Group:**
g = T_e(G) (tangent space at identity)
Bracket: [X,Y] = derivative of adjoint action

**Examples:**
- gl(n,ℝ) = Mₙ(ℝ), [X,Y] = XY - YX
- sl(n,ℝ) = {X : tr(X) = 0}
- so(n) = {X : X^T = -X}
- su(n) = {X : X* = -X, tr(X) = 0}

**Exponential Map:**
exp: g → G,  exp(X) = Σ_{k=0}^∞ X^k/k!
- Local diffeomorphism near 0
- For matrix groups: matrix exponential

**Representation of Lie Algebras:**
Homomorphism ρ: g → gl(V) preserving bracket.
- Adjoint representation: ad_X(Y) = [X,Y]
- Killing form: κ(X,Y) = tr(ad_X ∘ ad_Y)

**Semisimple Lie Algebras:**
No non-zero solvable ideals.
- Classification by Dynkin diagrams: Aₙ, Bₙ, Cₙ, Dₙ, E₆, E₇, E₈, F₄, G₂
- Cartan subalgebra, root systems, Weyl groups

**Weyl Character Formula:**
For irreducible representation with highest weight λ:
char(V_λ) = Σ_{w∈W} ε(w) e^{w(λ+ρ)} / Σ_{w∈W} ε(w) e^{w(ρ)}
where W is Weyl group, ρ is half-sum of positive roots.


## Homological Algebra

### Chain Complexes
A chain complex C• is a sequence of modules with maps dₙ: Cₙ → C_{n-1} such that d_{n-1} ∘ dₙ = 0.

**Homology:**
Hₙ(C) = ker(dₙ) / im(d_{n+1})

**Cochain Complex:**
Maps go up: dⁿ: Cⁿ → C^{n+1}, d^{n+1} ∘ dⁿ = 0
**Cohomology:** Hⁿ(C) = ker(dⁿ) / im(d^{n-1})

### Derived Functors

**Projective Resolution:**
... → P₂ → P₁ → P₀ → M → 0 with Pᵢ projective

**Injective Resolution:**
0 → M → I⁰ → I¹ → I² → ... with Iⁱ injective

**Ext:**
Extⁿ_R(M, N) = n-th right derived functor of Hom_R(M, -)
- Ext¹(M, N) classifies extensions 0 → N → E → M → 0
- Extⁿ(M, N) = 0 for n > 0 iff M is projective (or N is injective)

**Tor:**
Torₙ^R(M, N) = n-th left derived functor of M ⊗_R -
- Tor₁(M, N) = 0 iff M is flat
- Torₙ^ℤ(A, B) = 0 for n ≥ 2 (since ℤ is hereditary)

### Spectral Sequences
A spectral sequence is a sequence of pages Eʳ with differentials dʳ: Eʳ → Eʳ of degree r, where E^{r+1} = H(Eʳ, dʳ).

**Convergence:**
Eʳ ⇒ H*(C) means E^∞ is associated graded of filtration on H*(C).

**Leray-Serre Spectral Sequence:**
For fibration F → E → B:
E²_{p,q} = H_p(B; H_q(F)) ⇒ H_{p+q}(E)

**Examples:**
- Computing cohomology of total space from base and fiber
- Atiyah-Hirzebruch spectral sequence for generalized cohomology
