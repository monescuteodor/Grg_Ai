# CHAPTER 14: NONCOMMUTATIVE GEOMETRY & OPERATOR ALGEBRAS


## C*-Algebras

### Basics

**Definition:**
Banach *-algebra A with ||a*a|| = ||a||².
- *-operation: involution (a*)* = a, (ab)* = b*a*
- Examples: C(X) for compact X, B(H), K(H), group C*-algebras

**Spectrum:**
For a ∈ A: σ(a) = {λ ∈ ℂ : a - λ·1 not invertible}
- Non-empty compact subset of ℂ
- σ(a*) = σ(a)̄
- For normal a: ||a|| = sup{|λ| : λ ∈ σ(a)}

**Functional Calculus:**
For normal a ∈ A and f continuous on σ(a):
∃! f(a) ∈ A with σ(f(a)) = f(σ(a))
- Continuous functional calculus
- Borel functional calculus for von Neumann algebras

**Gelfand-Naimark Theorems:**
1. Commutative: A ≅ C(X) for X = spectrum of A
2. General: Every C*-algebra is *-isomorphic to closed *-subalgebra of B(H)

**Ideals & Quotients:**
- Closed two-sided ideals are *-ideals
- A/I is C*-algebra
- Primitive ideal: kernel of irreducible representation

### Classification

**K-Theory:**
K₀(A): Grothendieck group of projections in matrix algebras
K₁(A) = GL(A)/GL(A)₀
- Bott periodicity: Kₙ(A) ≅ K_{n+2}(A)
- Six-term exact sequence for extensions

**AF-Algebras (Approximately Finite):**
Inductive limit of finite-dimensional C*-algebras.
- Classified by ordered K₀ group (Elliott)
- Dimension group: K₀ with order unit
- Bratteli diagrams

**Simple C*-Algebras:**
No non-trivial closed ideals.
- UHF algebras: simple AF
- Cuntz algebras Oₙ: universal C*-algebra generated by n isometries
- Jiang-Su algebra Z: unique simple monotracial AF algebra

**Elliott Classification Program:**
Simple separable nuclear C*-algebras classified by invariant:
(K₀, K₁, T, ρ) where T = trace simplex, ρ = pairing
- Success for large classes (Huaxin Lin, Winter, et al.)
- Z-stability as regularity condition

### Von Neumann Algebras

**Definition:**
*-subalgebra of B(H) closed in weak operator topology.
- Double commutant theorem: M = M''
- Examples: L^∞(X), B(H), group von Neumann algebras

**Types:**
- **Type I:** Factor is B(H) for some Hilbert space H
- **Type II₁:** Factor with finite trace, no minimal projections
- **Type II_∞:** Infinite factor with semifinite trace
- **Type III:** No non-zero normal semifinite trace

**Murray-von Neumann Classification:**
- Type Iₙ: M ≅ Mₙ(ℂ)
- Type I_∞: M ≅ B(H)
- Type II₁: finite, continuous
- Type II_∞: properly infinite, semifinite
- Type III: purely infinite

**Factors:**
Center is trivial (scalar multiples of identity).
- Hyperfinite II₁ factor R: unique amenable II₁ factor
- Connes' classification of injective factors
- Free group factors: L(Fₙ) for n ≥ 2
- Free probability: Voiculescu's free entropy

**Tomita-Takesaki Theory:**
For von Neumann algebra M with faithful normal state φ:
- Modular operator Δ_φ
- Modular automorphism group σ_t^φ
- Connes' spectrum S(M) = ∩_φ σ(Δ_φ)
- Type III_λ for 0 ≤ λ ≤ 1

**Connes' Classification of Type III:**
- III₀: S(M) = {0,1}
- III_λ: S(M) = {0} ∪ {λ^n : n ∈ ℤ} for 0 < λ < 1
- III₁: S(M) = [0,∞)

### Noncommutative Geometry

**Spectral Triples:**
(A, H, D) where:
- A = *-algebra represented on H
- D = self-adjoint operator with compact resolvent
- [D,a] bounded for all a ∈ A

**Examples:**
- Commutative: A = C^∞(M), H = L²(S), D = Dirac operator
- Noncommutative torus: A_θ generated by unitaries U,V with UV = e^{2πiθ}VU
- Quantum groups

**Distance Formula:**
d(φ,ψ) = sup{|φ(a) - ψ(a)| : ||[D,a]|| ≤ 1}
- Recovers geodesic distance for manifolds
- Generalizes to noncommutative spaces

**Differential Forms:**
Ω^*_D(A) = universal differential graded algebra / junk forms
- d(a) = [D,a]
- Closed under d and wedge product

**Chern Character:**
ch(A,H,D) in cyclic homology
- Pairing with K-theory: index formula
- Local index formula (Connes-Moscovici)

**Cyclic Cohomology:**
HC^n(A) = cohomology of cyclic complex.
- Periodicity: S: HC^n → HC^{n+2}
- Connection to K-theory via Chern character

### Quantum Groups

**Hopf Algebras:**
Algebra H with comultiplication Δ: H → H⊗H, counit ε, antipode S.
- Δ(ab) = Δ(a)Δ(b)
- S(ab) = S(b)S(a)
- Examples: group algebra, function algebra, quantized enveloping algebras

**Compact Quantum Groups:**
(Woronowicz) C*-algebra A with comultiplication.
- Haar state: unique invariant state
- Representation theory similar to compact groups
- Examples: SU_q(2), quantum spheres

**Quantized Enveloping Algebras:**
U_q(g) for semisimple Lie algebra g.
- Deformation of U(g)
- q ≠ root of unity: similar representation theory
- q = root of unity: modular representation

**R-Matrix:**
R ∈ H⊗H satisfying Yang-Baxter equation.
- Quasitriangular Hopf algebra
- Braided tensor category
- Knot invariants (Jones, HOMFLY)

### Free Probability

**Noncommutative Probability Space:**
(A, φ) where A is *-algebra, φ is state.
- Random variables: self-adjoint elements
- Distribution: linear functional on polynomials

**Free Independence:**
a₁, ..., aₙ freely independent if:
φ(p₁(a_{i₁})...pₖ(a_{iₖ})) = 0 whenever φ(pⱼ(a_{iⱼ})) = 0 and adjacent indices differ.

**Free Convolution:**
For freely independent a, b:
μ_{a+b} = μ_a ⊞ μ_b
- Computed via R-transform: R_{μ_a⊞μ_b} = R_{μ_a} + R_{μ_b}

**Free Central Limit Theorem:**
For freely independent identically distributed aᵢ with φ(aᵢ) = 0, φ(aᵢ²) = 1:
(a₁+...+aₙ)/√n → semicircle distribution
- Semicircle: ρ(x) = (1/2π)√(4-x²) for |x| ≤ 2

**Applications:**
- Random matrix theory (asymptotic freeness)
- von Neumann algebras (free group factors)
- Quantum information theory

### Subfactors

**Jones Index:**
For inclusion of II₁ factors N ⊆ M:
[M:N] = dim_N(L²(M)) ∈ [1,∞]
- Jones' theorem: [M:N] ∈ {4cos²(π/n) : n ≥ 3} ∪ [4,∞]
- Values < 4 are discrete

**Standard Invariant:**
Lattice of higher relative commutants.
- Planar algebra (Jones)
- Classification of small index subfactors

**Applications:**
- Knot invariants (Jones polynomial)
- Topological quantum field theory
- Quantum computing
