# Grg_Ai

### I declare that I used AI in this project.

# Description
Trained Ai specialized in programing. 
The AI model is trained with .json file but also with .md files.

I trained Qwen 2.5 1.5B for better programming skils.

If you want more performance you can chose option 1.
If you don't want to install anything chose option 2.

# TO RUN, you have 2 options:
1. Install the version you want LOCALY on your PC and run it safe wherever you want:
    1. Go in Releases and download the version you want.(I recomand v1.1.0)
    2. Follow the README.md file specific to your wanted version.

2. You can test it on my server(from old laptop) on your browser:
    https://grg-ai.com/

# Details:
Model architecture: Qwen 2.5 1.5B (GGUF)
System: minimum 8GB of RAM requiered and minimum 4 cores CPU
GPU is recomanded for higher performance.

In all the versions all your data stores only into local memory!

The web page is hosted by cloudflare and the server were the AI runs is an old laptop in my room:
https://grg-ai.com/
