# Algebra Complete Reference

## Number Types

Natural numbers (counting numbers): 1, 2, 3, 4, … — positive integers only.
Whole numbers: 0, 1, 2, 3, … — natural numbers plus zero.
Integers: … −3, −2, −1, 0, 1, 2, 3, … — positive, negative, and zero.
Rational numbers: any number expressible as p/q where p and q are integers and q ≠ 0. Includes terminating decimals (0.25 = 1/4) and repeating decimals (0.333… = 1/3).
Irrational numbers: cannot be expressed as p/q. Decimal expansion is infinite and non-repeating. Examples: √2 = 1.41421…, π = 3.14159…, e = 2.71828…
Real numbers: all rational and irrational numbers together; every point on the number line.
Complex numbers: a + bi where a,b are real and i = √(−1). Real numbers are a special case with b = 0.

Number line: negative numbers to the left of 0, positive to the right. Absolute value |x| is the distance from 0, always ≥ 0.

## Algebraic Properties

Commutative property of addition: a + b = b + a
Commutative property of multiplication: a · b = b · a
Subtraction and division are NOT commutative.

Associative property of addition: (a + b) + c = a + (b + c)
Associative property of multiplication: (a · b) · c = a · (b · c)

Distributive property: a(b + c) = ab + ac and a(b − c) = ab − ac
Example: 3(x + 4) = 3x + 12
Example: −2(x − 5) = −2x + 10

Identity elements: a + 0 = a (additive identity), a · 1 = a (multiplicative identity).
Inverse elements: a + (−a) = 0 (additive inverse), a · (1/a) = 1 for a ≠ 0 (multiplicative inverse).
Zero product property: if a · b = 0 then a = 0 or b = 0 (or both).

Order of operations (PEMDAS/BODMAS): Parentheses → Exponents → Multiplication/Division (left to right) → Addition/Subtraction (left to right).

## Variables, Expressions and Equations

A variable is a letter representing an unknown value. Common variables: x, y, z, n, t.
An expression is a combination of numbers, variables, and operations with no equals sign. Example: 3x² − 2x + 7.
An equation states that two expressions are equal. Example: 3x + 5 = 14.
A formula is an equation relating multiple quantities. Example: A = πr².

Terms: parts of an expression separated by + or −. In 4x² − 3x + 1, the terms are 4x², −3x, 1.
Coefficient: the numerical factor of a term. In 7x, the coefficient is 7.
Constant term: a term with no variable. In 4x + 9, the constant is 9.
Like terms: terms with the same variable(s) raised to the same power(s). 3x² and −5x² are like terms.

Combining like terms: 5x + 3x = 8x; 7y² − 2y² + y = 5y² + y.
Simplifying expressions: expand brackets, then combine like terms.
Example: 2(x + 3) − (x − 1) = 2x + 6 − x + 1 = x + 7

## Solving Linear Equations

A linear equation in one variable has the form ax + b = c.
Goal: isolate the variable by performing the same operation on both sides.
Steps: (1) distribute/expand, (2) combine like terms, (3) move variable terms to one side, (4) move constants to the other, (5) divide by the coefficient.

Example: 3x − 4 = 11
3x = 15
x = 5

Example with fractions: (x/2) + 3 = 7 → x/2 = 4 → x = 8

Example with variables on both sides: 5x + 2 = 3x − 6 → 2x = −8 → x = −4

Special cases:
- No solution (contradiction): 2x + 3 = 2x + 7 → 3 = 7 (false). No values satisfy it.
- All real solutions (identity): 2x + 4 = 2(x + 2) → 4 = 4 (always true). Every real number is a solution.

## Linear Inequalities

Solving inequalities: same steps as equations, BUT when multiplying or dividing by a negative number, REVERSE the inequality sign.

Example: −3x > 9 → x < −3 (sign flipped when dividing by −3)
Example: 2x − 5 ≤ 7 → 2x ≤ 12 → x ≤ 6

Interval notation: x > 3 is (3, ∞); x ≤ 5 is (−∞, 5]; 2 < x ≤ 8 is (2, 8].

Compound inequalities:
- AND (intersection): −2 < x AND x ≤ 5 → −2 < x ≤ 5 (values in both)
- OR (union): x < 1 OR x > 4 → (−∞, 1) ∪ (4, ∞)

Absolute value equations: |x − 3| = 7 → x − 3 = 7 or x − 3 = −7 → x = 10 or x = −4
Absolute value inequalities: |x| < a → −a < x < a; |x| > a → x < −a or x > a

## Graphing Linear Equations

Standard form: Ax + By = C
Slope-intercept form: y = mx + b, where m = slope, b = y-intercept.
Point-slope form: y − y₁ = m(x − x₁), used when you know a point (x₁, y₁) and slope m.

Slope formula: m = (y₂ − y₁)/(x₂ − x₁) = rise/run
Positive slope: line goes up left to right. Negative slope: goes down. Zero slope: horizontal. Undefined slope: vertical.

Parallel lines: same slope (m₁ = m₂), different y-intercepts.
Perpendicular lines: slopes are negative reciprocals (m₁ · m₂ = −1). Example: slopes 2 and −1/2.

Finding intercepts:
- x-intercept: set y = 0 and solve for x
- y-intercept: set x = 0 and solve for y (equals b in y = mx + b)

Distance between two points: d = √((x₂−x₁)² + (y₂−y₁)²)
Midpoint: ((x₁+x₂)/2, (y₁+y₂)/2)

## Systems of Linear Equations

A system of two equations with two unknowns (x, y).

Types of solutions:
- One solution: lines intersect at one point (consistent and independent)
- No solution: parallel lines (inconsistent)
- Infinitely many solutions: same line (consistent and dependent)

Substitution method: solve one equation for one variable, substitute into the other.
Example: y = 2x + 1 and 3x + y = 11 → 3x + (2x + 1) = 11 → 5x = 10 → x = 2, y = 5.

Elimination (addition) method: multiply equations so one variable cancels.
Example: 2x + 3y = 12 and 4x − 3y = 6 → add → 6x = 18 → x = 3 → y = 2.

Graphing method: plot both lines; intersection is the solution.

3×3 systems: three equations, three unknowns. Use elimination or substitution repeatedly, or row reduction.

## Exponents and Radicals

Exponent rules:
- Product rule: aᵐ · aⁿ = aᵐ⁺ⁿ
- Quotient rule: aᵐ / aⁿ = aᵐ⁻ⁿ (a ≠ 0)
- Power rule: (aᵐ)ⁿ = aᵐⁿ
- Power of product: (ab)ⁿ = aⁿbⁿ
- Power of quotient: (a/b)ⁿ = aⁿ/bⁿ
- Zero exponent: a⁰ = 1 (a ≠ 0)
- Negative exponent: a⁻ⁿ = 1/aⁿ

Scientific notation: a number written as c × 10ⁿ where 1 ≤ |c| < 10. Example: 0.00045 = 4.5 × 10⁻⁴.

Radicals and fractional exponents:
- √a = a^(1/2); ∛a = a^(1/3); ⁿ√a = a^(1/n)
- a^(m/n) = (ⁿ√a)ᵐ = ⁿ√(aᵐ)
- √(ab) = √a · √b; √(a/b) = √a/√b
- √a + √b ≠ √(a+b) (common mistake!)

Simplifying radicals: √72 = √(36·2) = 6√2
Rationalizing denominators: 1/√3 = √3/3 (multiply numerator and denominator by √3).

## Polynomials

A polynomial is a sum of terms of the form aₙxⁿ + … + a₁x + a₀.
Degree: highest power of x. Linear = degree 1, Quadratic = degree 2, Cubic = degree 3.
Leading coefficient: coefficient of the highest-degree term.

Adding/subtracting polynomials: combine like terms.
(3x² − 2x + 1) + (x² + 4x − 5) = 4x² + 2x − 4

Multiplying polynomials: distribute every term of one polynomial to every term of the other.
(x + 3)(x − 2) = x² − 2x + 3x − 6 = x² + x − 6

FOIL method (for two binomials): First + Outer + Inner + Last.
(a + b)(c + d) = ac + ad + bc + bd

Special products (memorize these):
- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²
- (a + b)(a − b) = a² − b² (difference of squares)
- (a + b)³ = a³ + 3a²b + 3ab² + b³

Polynomial long division and synthetic division: used to divide polynomials, similar to numeric long division.

## Factoring

Factoring is writing a polynomial as a product of simpler polynomials.

Greatest Common Factor (GCF): factor out the largest common factor first.
6x³ + 9x² = 3x²(2x + 3)

Factoring trinomials ax² + bx + c:
- When a = 1: find two numbers that multiply to c and add to b.
  x² + 5x + 6 = (x + 2)(x + 3) because 2·3 = 6 and 2+3 = 5
- When a ≠ 1: use AC method or trial and error.
  2x² + 7x + 3: AC = 2·3 = 6, factors of 6 that add to 7: 1 and 6.
  2x² + x + 6x + 3 = x(2x+1) + 3(2x+1) = (x+3)(2x+1)

Special factoring patterns:
- Difference of squares: a² − b² = (a+b)(a−b). Example: x² − 25 = (x+5)(x−5)
- Perfect square trinomial: a² + 2ab + b² = (a+b)²; a² − 2ab + b² = (a−b)²
- Sum of cubes: a³ + b³ = (a+b)(a²−ab+b²)
- Difference of cubes: a³ − b³ = (a−b)(a²+ab+b²)

Factoring by grouping (4 terms): group into pairs, factor each, then factor the common binomial.
x³ + 2x² + 3x + 6 = x²(x+2) + 3(x+2) = (x²+3)(x+2)

Always check: can any factor be factored further? Is the leading coefficient positive?

## Quadratic Equations

Standard form: ax² + bx + c = 0 (a ≠ 0).

Methods to solve:
1. Factoring: factor the quadratic, set each factor to zero.
   x² − 5x + 6 = 0 → (x−2)(x−3) = 0 → x = 2 or x = 3

2. Square root method (when bx term is absent):
   x² = 49 → x = ±7; (x−3)² = 16 → x−3 = ±4 → x = 7 or x = −1

3. Completing the square:
   x² + 6x + 5 = 0 → x² + 6x = −5 → x² + 6x + 9 = 4 → (x+3)² = 4 → x = −1 or x = −5

4. Quadratic formula (always works):
   x = (−b ± √(b²−4ac)) / (2a)

Discriminant: D = b² − 4ac
- D > 0: two distinct real solutions
- D = 0: one repeated real solution (double root)
- D < 0: two complex conjugate solutions (no real solutions)

Vertex form: y = a(x−h)² + k, vertex at (h, k).
Converting: complete the square or use h = −b/(2a), k = f(h).

Parabola opens up if a > 0 (minimum at vertex), down if a < 0 (maximum at vertex).
x-intercepts are the real roots; y-intercept is c (set x=0).
Axis of symmetry: x = −b/(2a)

## Functions

A function f maps each input x to exactly one output f(x). Written as f: A → B.
Vertical line test: a graph is a function if every vertical line crosses it at most once.

Domain: all valid input values (x values).
Range: all possible output values (y values or f(x) values).

Common domain restrictions: avoid division by zero; avoid square roots of negative numbers.
Example: f(x) = 1/(x−3) has domain x ≠ 3.
Example: g(x) = √(x+4) has domain x ≥ −4.

Function notation: f(x) means the value of function f at input x. f(2) means substitute x = 2.

Operations on functions:
- Sum: (f+g)(x) = f(x) + g(x)
- Difference: (f−g)(x) = f(x) − g(x)
- Product: (f·g)(x) = f(x)·g(x)
- Quotient: (f/g)(x) = f(x)/g(x), domain excludes points where g(x) = 0

Composition: (f∘g)(x) = f(g(x)). Evaluate g first, then apply f to the result.
Example: f(x) = x², g(x) = x+1. (f∘g)(3) = f(g(3)) = f(4) = 16.

Inverse functions: f⁻¹ undoes f. f(f⁻¹(x)) = x and f⁻¹(f(x)) = x.
Finding inverse: swap x and y, then solve for y. Domain of f⁻¹ = Range of f.
Horizontal line test: f has an inverse if every horizontal line crosses the graph at most once.

Even functions: f(−x) = f(x) — symmetric about y-axis. Example: f(x) = x².
Odd functions: f(−x) = −f(x) — symmetric about origin. Example: f(x) = x³.

## Rational Expressions

A rational expression is a fraction with polynomials in numerator and/or denominator.

Simplifying: factor numerator and denominator, cancel common factors.
(x²−4)/(x+2) = (x+2)(x−2)/(x+2) = x−2, provided x ≠ −2.

Multiplying: multiply numerators, multiply denominators, simplify.
(a/b) · (c/d) = ac/bd

Dividing: multiply by the reciprocal.
(a/b) ÷ (c/d) = (a/b) · (d/c) = ad/bc

Adding/subtracting: find LCD (Least Common Denominator), convert fractions, then add/subtract numerators.
1/(x+1) + 2/(x−1) = (x−1 + 2x+2) / ((x+1)(x−1)) = (3x+1)/(x²−1)

Complex fractions: simplify numerator and denominator separately, then divide.

Solving rational equations: multiply both sides by the LCD, then solve. Always check for extraneous solutions (values that make the original denominator zero).

## Logarithms

Logarithm definition: logₐ(x) = y means aʸ = x. (a > 0, a ≠ 1, x > 0)
Common log: log(x) = log₁₀(x)
Natural log: ln(x) = logₑ(x), where e ≈ 2.71828

Logarithm properties:
- Product rule: logₐ(MN) = logₐ(M) + logₐ(N)
- Quotient rule: logₐ(M/N) = logₐ(M) − logₐ(N)
- Power rule: logₐ(Mⁿ) = n·logₐ(M)
- Change of base: logₐ(x) = log(x)/log(a) = ln(x)/ln(a)
- logₐ(a) = 1; logₐ(1) = 0; logₐ(aˣ) = x; aˡᵒᵍₐˣ = x

Solving exponential equations: take log of both sides.
Example: 3ˣ = 81 → x·log(3) = log(81) → x = log(81)/log(3) = 4

Solving logarithmic equations: convert to exponential form.
Example: log₂(x) = 5 → x = 2⁵ = 32

Exponential growth/decay: A = A₀·eᵏᵗ or A = A₀·(1+r)ᵗ

## Sequences and Series

Arithmetic sequence: each term differs by a constant d (common difference).
General term: aₙ = a₁ + (n−1)d
Sum of n terms: Sₙ = n(a₁ + aₙ)/2 = n(2a₁ + (n−1)d)/2
Example: 3, 7, 11, 15, … (d=4). a₁₀ = 3 + 9·4 = 39.

Geometric sequence: each term is multiplied by a constant r (common ratio).
General term: aₙ = a₁ · rⁿ⁻¹
Sum of n terms: Sₙ = a₁(1−rⁿ)/(1−r) for r ≠ 1
Infinite geometric series (|r| < 1): S∞ = a₁/(1−r)
Example: 2, 6, 18, 54, … (r=3). a₅ = 2·3⁴ = 162.

Sigma notation: Σᵢ₌₁ⁿ aᵢ means the sum of terms a₁ through aₙ.

## Matrices and Determinants

A matrix is a rectangular array of numbers arranged in rows and columns.
Size: m×n means m rows, n columns.

Matrix addition: add corresponding elements (same size only).
Scalar multiplication: multiply every element by the scalar.
Matrix multiplication: (A·B)ᵢⱼ = sum of row i of A times column j of B. Only defined if columns of A = rows of B.

Identity matrix I: square matrix with 1s on diagonal, 0s elsewhere. AI = IA = A.
Zero matrix: all entries are zero.

Determinant of a 2×2 matrix [[a,b],[c,d]]: det = ad − bc
Determinant of 3×3 (cofactor expansion): expand along any row or column.

Inverse of 2×2: if det ≠ 0, [[a,b],[c,d]]⁻¹ = (1/det)·[[d,−b],[−c,a]]
A matrix is invertible (non-singular) if and only if its determinant ≠ 0.

Solving systems using matrices (Cramer's Rule, row reduction / Gaussian elimination):
Augmented matrix [A|b], reduce to row echelon form, back-substitute.

## Quadratic Functions and Parabolas

f(x) = ax² + bx + c is a quadratic function; its graph is a parabola.

Key features:
- Vertex: (h, k) where h = −b/(2a), k = f(h)
- Axis of symmetry: x = h
- y-intercept: (0, c)
- x-intercepts (roots): solve f(x) = 0 using quadratic formula or factoring
- Opens upward if a > 0 (minimum at vertex), downward if a < 0 (maximum at vertex)

Vertex form: f(x) = a(x−h)² + k makes the vertex (h,k) immediately visible.
Range: if a > 0, range is [k, ∞); if a < 0, range is (−∞, k].

Transformations from parent y = x²:
- y = x² + k: shift up/down by k
- y = (x−h)²: shift left/right by h
- y = ax²: vertical stretch (|a|>1) or compression (|a|<1)
- y = −x²: reflection over x-axis

## Complex Numbers

Imaginary unit: i = √(−1), so i² = −1.
Complex number: a + bi where a = real part, b = imaginary part.

Operations:
- Add/subtract: (a+bi) ± (c+di) = (a±c) + (b±d)i
- Multiply: (a+bi)(c+di) = ac + adi + bci + bdi² = (ac−bd) + (ad+bc)i
- Conjugate of a+bi is a−bi. Product of conjugates: (a+bi)(a−bi) = a²+b²
- Divide: multiply numerator and denominator by conjugate of denominator.
  (2+3i)/(1−i) · (1+i)/(1+i) = (2+2i+3i+3i²)/(1+1) = (2+5i−3)/2 = (−1+5i)/2

Powers of i: i¹=i, i²=−1, i³=−i, i⁴=1, then repeats (cycle of 4).
|a+bi| = √(a²+b²) is the modulus (distance from origin in complex plane).

Solving equations with complex solutions:
x² + 4 = 0 → x² = −4 → x = ±2i
x² + 2x + 5 = 0 → x = (−2 ± √(4−20))/2 = (−2 ± 4i)/2 = −1 ± 2i
