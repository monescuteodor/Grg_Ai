    MCP servers — connect external tools
    Give Grg Code superpowers: filesystem, GitHub, databases, browsers and more via the Model Context Protocol. Servers run via npx and their tools appear to the agent automatically.
    Slash commands
    Reusable prompts you trigger by typing /name. Use $ARGUMENTS to insert whatever you type after the command.
    Skills & knowledge
    Dense know-how the agent loads on demand before building (stacks, platforms, best practices). Add your own or customize the built-ins — the agent picks the right one automatically.
    Templates
    Ready-to-scaffold starters the agent creates with scaffold("name"). Add your own or customize the built-ins.
    Project memory — GRGCODE.md
    Durable notes about this project (how to run/build/test, conventions, gotchas). Grg Code loads this into context every session.
    Checkpoints / Undo
    Grg Code snapshots files before it changes them in a task. Revert any task's changes with one click.
