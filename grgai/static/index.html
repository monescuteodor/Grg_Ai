⬇️ Download the miner

Everything you need to mine — node, miner, wallet, and a one-click script. 64-bit x86, CPU-only.

Windows (.zip) Linux (.tar.gz)

Unzip, read README.txt, run mine. Create a wallet first with nhash-wallet newwallet me.

⛏️ Mine nHash

Earn nHash on any x86 PC — CoreHash is CPU-only (ASIC/GPU-resistant). Point the miner at the pool with your own nHash address:

nhash-miner 192.168.50.220:9350 <YOUR_ADDRESS>
  1. Get nhash-miner + nhash-wallet, then run nhash-wallet newwallet me to create your address.
  2. Run the command above with your address — each block found pays ~50 nHash.
  3. Spend it here on GrgPro, or send it to friends.
